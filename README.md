# 路線検索CLIツール 🚉

Yahoo!路線情報から乗換案内（所要時間・乗換回数・料金・乗換詳細）をコマンドラインで取得するPythonスクリプトです。

[English README is here](./README_EN.md)

## 機能

- 出発駅・到着駅を対話形式で入力
- 「出発時間基準」「到着時間基準」の検索タイプを選択可能
- 日時を「今日」または任意の日付・時刻で指定可能
- 検索結果として以下を表示：
  - 所要時間
  - 乗換回数
  - 料金
  - 乗換ごとの駅名・路線名・所要時間・区間料金

## 必要環境

- Python 3.9以上

### 依存パッケージ

```
requests
beautifulsoup4
```

インストール方法：

```bash
pip install requests beautifulsoup4
```

## 使い方

```bash
python train.py
```

実行すると、対話形式で以下を順に入力します：

1. **出発駅を入力してください：** 例）和歌山
2. **到着駅を入力してください：** 例）難波
3. **出発時間で検索するなら1、到着時間で検索するなら4を入力してください：**
4. **日付を今日にするなら 1、自分で指定するなら 2 を入力してください：**
   - `2`を選んだ場合、月・日を追加で入力
5. **時（0-23）：** / **分（0-59）：**

入力が完了すると、検索に使用したURLと経路情報がコンソールに出力されます。

## 注意事項・既知の制限

- Yahoo!路線情報のページ構造に依存したスクレイピングのため、サイト側の仕様変更により動作しなくなる可能性があります。
- 検索年（`year`）が`2025`にハードコードされているため、翌年以降は手動で変更する必要があります。
- 駅名は入力ミスや同名駅の存在により、想定と異なる経路が返される場合があります。
- HTTPリクエストのエラーハンドリング（タイムアウト・接続エラー・要素未検出など）は実装されていないため、通信エラーやページ構造の変化時には例外で停止します。
